# Meadow plot tutorial

This repository provides three ways to create meadow plots and candidate-peak summaries from windowed nucleotide diversity (π) and Fst output generated by [`pixy`](https://pixy.readthedocs.io/):

1. **Website:** [paigeduffin.github.io/meadow_plot_tutorial](https://paigeduffin.github.io/meadow_plot_tutorial/) presents the tutorial as a polished, copy-and-run guide.
2. **Command line:** [`scripts/meadow_plot_cli.R`](scripts/meadow_plot_cli.R) runs the complete analysis from a terminal.
3. **R Markdown:** [`tutorials/meadow_plot_tutorial.Rmd`](tutorials/meadow_plot_tutorial.Rmd) supports a more interactive, section-by-section workflow.

## Quick start

Clone the repository:

```bash
git clone https://github.com/paigeduffin/meadow_plot_tutorial.git
```

Install the required R packages:

```r
install.packages(c(
  "dplyr", "tidyr", "readr", "ggplot2", "tibble",
  "gridExtra", "ggtext", "scales", "gtable"
))
```

Place the four required input files in `input/`, then run the command-line version with the absolute path to the cloned project:

```bash
Rscript scripts/meadow_plot_cli.R /absolute/path/to/meadow_plot_tutorial
```

The command-line script does not change the working directory. Paths supplied after the project directory may be absolute or relative to the project directory.

## Required input files

| File | Required columns |
| --- | --- |
| Fst output | `pop1`, `pop2`, `chromosome`, `window_pos_1`, `window_pos_2`, `avg_wc_fst` |
| π output | `pop`, `chromosome`, `window_pos_1`, `window_pos_2`, `avg_pi` |
| Comparison map | `comp`, `population_1`, `population_2`, `plot_order` |
| Chromosome map | `chromosome`, `chromo.num` |

The default filenames and full command-line syntax are documented in [`input/README.md`](input/README.md) and are displayed with:

```bash
Rscript scripts/meadow_plot_cli.R --help
```

## Outputs

Processed tables are written to `wrangled_data/`. Meadow plots and the candidate-peak size plot are written to `plots/`. These output directories are created automatically and are ignored by Git.
